# linear_project

ไฟล์ที่ส่งไปล่าสุดมี 2 ไฟล์ เป็น Jupyter Notebook (.ipynb) ทั้งคู่ คือไฟล์ที่มีโค้ด Python กับคำอธิบายภาษาไทยสลับกันเป็นช่องๆ (cell) เปิดได้ใน Jupyter, VS Code หรือ Google Colab

📘 1. model2_pca.ipynb = ตัวสร้างโมเดล

ไฟล์หลักของงานนาย ทำตามขั้นที่เราคิดมือในโมเดลจิ๋วทุกขั้น แต่ใช้ข้อมูลจริง 24 ฟีเจอร์ แบ่งเป็น 3 ส่วน:

ส่วน	ทำอะไร
A	สร้างโมเดลทีละขั้น: หา μ → C → eigen → ฉายลง k ทิศ → หา centroid → ฟังก์ชัน predict()
B	ไม่มีไฟล์ test เลยแบ่งข้อมูลส่วนหนึ่งมาเป็นข้อสอบซ้อม (validation) เพื่อวัดความแม่นและเลือก k (ได้ k = 7)
C	เทรนโมเดลจริงด้วยข้อมูลทั้ง 1080 แถว แล้วบันทึกเป็นไฟล์ model2.npz

model2.npz คือ "ตัวโมเดล" ที่ต้องส่งให้ทีม Wi-Fi ข้างในเป็นตัวเลขไม่กี่ชุด: μ, W, centroid, ชื่อกิจกรรม และค่า k (ช่อง min/max สำหรับปรับสเกลยังว่างอยู่ ต้องรอค่าจากเพื่อน)

🖥️ 2. model2_interactive.ipynb = หน้าจอทดลองทาย

ไฟล์ที่นายขอให้มี interface สำหรับเลือกแถว รันจนจบแล้วจะมีหน้าจอให้:

เลือกแถวที่อยากดู แล้วดูว่าโมเดลทายว่าอะไร ถูกหรือผิด
ดูทำไมมันทายแบบนั้น ผ่านระยะห่างจากแถวนั้นไปถึง centroid แต่ละตัว และกราฟ
กรองดูเฉพาะคน เฉพาะกิจกรรม หรือเฉพาะแถวที่ทายผิดได้
เลื่อนเปลี่ยนค่า k แล้วดูผลได้ทันที

ตอนนี้ยังไม่มีไฟล์ test หน้าจอเลยให้เลือกดูได้เฉพาะแถวช่วงท้าย 30% ของแต่ละคน/กิจกรรม ซึ่งโมเดลไม่ได้ใช้ตอนเทรน
